# 科学革命 0.1.0 实机验收清单

当前为组装准备版，以下项目均待实机验收。每项记录系统版本、芯片、介质、结果与问题；完成前不标记正式发行。

## 设备与介质

- Windows 10 x64、Windows 11 x64。
- macOS 12 及计划支持的较新版本；Intel 和 Apple Silicon 各一台。
- 建议至少 64 GB U 盘，exFAT 为候选；本准备版 Mac ZIP 在 Mac 本机文件系统解包，应用从本机启动、视频从 U 盘读取。尚未验收 `.app` 直接从 exFAT 启动。

## 每种目标环境

- 核对来源及校验值，记录首次启动提示、手动允许步骤、应用窗口是否可见。
- Windows 从完整 Windows 目录启动；Mac 原生解包后签名检查通过，保留 U 盘连接并选择出版物根目录。
- 断网启动、六主题与44讲目录、搜索、收藏、继续观看。
- 44讲逐一打开，核对标题和对应视频；检查两处扩展名前有空格的视频路径。
- 播放、暂停、拖动、音量、全屏、上一讲/下一讲、返回目录位置、画面比例；核对5.1声道讲次声音。
- 收藏和进度跨应用关闭重启保留；记录保存在当前系统用户目录，不写入 U 盘。
- 1280×720、1920×1080、4K与系统缩放；检查字体、长标题、控件与顶部背景。
- 退出后安全弹出，再插入；盘符/挂载名变化后重新选择内容目录。
- 视频缺失、播放期间介质断开、内容目录找不到时反馈清楚，可返回目录恢复。
- 不预先关闭系统保护或移除隔离属性；记录受管理设备的策略限制。
