## 进程与接口

`electron/main.mjs` 负责启动、内容目录、受限媒体协议和用户数据。窗口启用 `contextIsolation`、`sandbox`、`webSecurity`，关闭 `nodeIntegration`。界面没有 `require`、Node 进程或任意文件读取接口。

`electron/preload.cjs` 只暴露初始化、保存阅读状态、重新查找内容、选择内容文件夹、关闭前通知和提交关闭前状态六个方法。主进程校验调用来源是当前窗口的主框架。新窗口、webview、下载和外部导航被禁用；构建界面有内容安全策略，运行时仅允许应用与媒体协议。

## 内容根目录与视频

`electron/content.mjs` 查找上次成功选择的目录，再沿应用目录、运行程序目录、资源目录和工作目录的父目录查找。开发时显式设置 `SR_CONTENT_ROOT` 会优先使用该目录并关闭父目录自动查找，仍允许用户手动选择恢复。代码不含工作区绝对路径或固定盘符。

有效根目录包含 `视频/` 和 UTF-8 清单。发行布局读取根目录 `content.json`；开发布局读取 `desktop-app/src/content.json`。外部清单必须与本版本锁定清单的数据一致，不能增加讲次、改变路径或注入新界面文案。清单字段的 JSON 排列顺序不影响校验。

未找到内容时显示重新查找和选择文件夹入口。选择文件夹使用原生系统对话框，成功后保存至本机用户记录；介质断开、文件缺失或无法解码时，播放页提供重新载入、选择内容文件夹和返回主题目录。

媒体地址形如 `sr-media://publication/astronomy-06`，只接受已锁定讲次 ID。每次请求重新解析真实路径并检查其位于内容根目录的 `视频/` 中，拒绝路径越界和符号链接/目录联接逃逸。中文、文件名空格和扩展名前的空格保持原样。

`electron/stream.mjs` 支持 GET、HEAD、单段 Range、开放末端和末尾范围，非法范围返回 416，未知 ID 返回 404；文件流按请求范围读取，不把视频整体加载进内存。

## 用户记录与完成判断

收藏、每讲位置、更新时间、累计实际播放区间、完成状态和上次内容根目录保存到：

| 系统 | 记录文件 |
| --- | --- |
| Windows | `%APPDATA%/Scientific-Revolution/reader-state.v1.json` |
| macOS | `~/Library/Application Support/Scientific-Revolution/reader-state.v1.json` |

`SR_USER_DATA` 可为独立开发检查指定临时用户目录。正式运行不写回 U 盘、源视频目录或浏览器 localStorage，也不虚构或自动导入浏览器原型记录。

主进程校验并规范化阅读状态，串行写临时文件后原子替换正式文件。在拒绝同目录重命名并返回 EXDEV 的虚拟文件系统上，先保留旧记录 `.backup`，再复制新记录；这种兼容路径不具有原子替换保证。损坏记录尽力保存为 `.unreadable-*` 副本，存储失败显示提示并保留本次会话操作。退出时先通知播放器收集最后位置，再等待保存；渲染进程无响应时最多等待 2.5 秒并保留已经提交的状态。

实际播放区间按媒体时间及实际经过时间记录，拖动产生的间隔不会计入覆盖；重叠区间合并、范围限制在视频时长内。仅自然结束且覆盖至少 90% 时标为已看完。已经完成的状态在再次播放后保留。记录的读取与保存使用同一个规范化实现。
